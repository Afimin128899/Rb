# До рассвета

Хоррор для Roblox. Осмотри комнату, поговори с посетителем через дверь и реши, стоит ли открывать.

Открой `UntilDawn.rbxlx` в Roblox Studio и нажми **Play (F5)**. В главном меню выбери **Начать**, затем одну из трёх комнат на 1–4 игроков. Соло на решение даётся до 15 секунд, в группе — до 30 секунд.

Клиентский и серверный скрипты встроены в проект. Архив `UntilDawn-Audio.zip` содержит оригинальные WAV и инструкцию по их подключению.
